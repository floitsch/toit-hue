## Components

### Hue Discovery Client
- **Purpose:** Discovers local Philips Hue bridges on the network using `discovery.meethue.com`.
- **Location:** `src/hue.toit`
- **Dependencies:** `http`, `certificate-roots`, `encoding.json`, `net`

### OpenAPI to Toit Generator
- **Purpose:** Parses OpenAPI 3 specifications and generates Toit client code. It handles JSON Schema resolution, naming collisions, and mustache template rendering.
- **Location:** `tools/openapi.toit`, `tools/openapi-gen.toit`, `tools/toit-gen/`
- **Dependencies:** `encoding.yaml`, `fs`, `host.file`, `mustache`, `json-schema/`

### Hue API Scraper
- **Purpose:** Parses downloaded Philips Hue HTML API documentation into structured data using an XML/HTML parser.
- **Location:** `tools/hue_parser.toit`
- **Dependencies:** `host.file`, `encoding.json`, `monitor`, `.xml-parser`

## Data Flow

1. **Scraping**: `hue_parser.toit` reads `Hue CLIP API.html` and extracts endpoints, methods, and parameters.
2. **Generation**: `openapi-gen.toit` reads standard OpenAPI docs and outputs Toit `.toit` source code for the client API.
3. **Runtime**: The generated Toit client leverages `http` and `net` packages to send requests to Hue devices or other APIs.
